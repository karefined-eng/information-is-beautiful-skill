Information is Beautiful — an interactive tribute

A fan-made homage to David McCandless' atlas of infographics, and the home of information-is-beautiful: an MIT-licensed Agent Skill that teaches AI coding agents the craft of honest, editorial-quality information design — five checkable laws, a chart-matching decision table, and a 25-point quality audit.

Install the skill

Run npx skills add karefined-eng/information-is-beautiful-skill, or read the skill instructions directly. It works with Claude Code, Codex, Cursor, ZCode and any Agent-Skills-compatible agent.

Explore

The full interactive experience — the atlas, the playground, the book — loads when JavaScript is enabled. Meanwhile: browse the source on GitHub, or read the provenance of every principle.

Beautiful enough to be looked at. Honest enough to be trusted.
