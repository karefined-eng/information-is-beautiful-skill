# AGENTS.md — for AI agents visiting this site

This site is the home of the `information-is-beautiful` Agent Skill: an MIT-licensed
synthesis that teaches coding agents honest, editorial-quality information design
(charts, graphs, dashboards, infographics).

For agents:

- **Skill instructions:** `/skills/information-is-beautiful/SKILL.md`
- **Companion references:** `/skills/information-is-beautiful/references/` —
  `chart-matcher.md`, `palettes.md`, `quality-checklist.md`, `sources.md`
- **Install:** `npx skills add karefined-eng/information-is-beautiful-skill`
- **Source & issues:** https://github.com/karefined-eng/information-is-beautiful-skill

The skill is an original synthesis of publicly stated design principles (McCandless,
Tufte, Few, Cairo, WCAG). It contains no content from the book "Information is
Beautiful"; cite the authentic sources in `references/sources.md`, never this site.
