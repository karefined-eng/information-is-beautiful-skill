# Quality checklist — the beauty audit

Run before delivering any visual artifact. Every "no" is a defect to fix, not a style preference.

## Honesty

- [ ] Quantitative length axes start at zero, or the break is drawn and stated.
- [ ] Areas encode value by area, radii by root(value) — never radius ∝ value.
- [ ] Units, year, and geography are named wherever numbers appear.
- [ ] Source and vintage are cited on the artifact itself.
- [ ] Rates shown where counts would mislead (population above all).
- [ ] Uncertainty is drawn, not hidden; estimates look different from actuals.

## Form

- [ ] The geometry matches the comparison (matched against `chart-matcher.md`).
- [ ] Only one insight per visual — the rest became small multiples or separate scenes.
- [ ] Sorting carries meaning (magnitude/time/narrative), not alphabet soup.
- [ ] No element from the default software theme survived unexamined.

## Ink & colour

- [ ] Every remaining element passes deletion: remove it and meaning is lost.
- [ ] One accent hue, applied to exactly one thing.
- [ ] Colour channels are doubled (colour + position/label/pattern), never solo.
- [ ] Contrast meets ≥ 3:1 marks, ≥ 4.5:1 small text.
- [ ] Greys do the context work; colour does the speaking.

## Story

- [ ] The title is the insight, not the topic — a full claim a critic could argue with.
- [ ] Labels sit beside their marks; no legend standoff across the chart.
- [ ] The one annotation that answers "so what?" exists.
- [ ] Three reading depths work: glance says the headline; study shows the axes; immerse reveals source, method, caveat.

## The three physical tests

- [ ] **Squint test** — the dominant pattern survives blur.
- [ ] **Cover-the-legend test** — the visual decodes without its legend.
- [ ] **Inversion test** — reverse the headline; the graphic would look wrong, not conveniently plausible.

## Delivery

- [ ] True alt text written: what it shows (the finding), not what it is (the chart type).
- [ ] Hand-off includes: graphic, insight sentence, source line, this checklist passed.
